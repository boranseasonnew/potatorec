# Potato Recorder — Русский

**Руководство пользователя**

Небольшая родная Windows-студия для записи игрового процесса.

## Начало работы

Установите FFmpeg 8.1 или новее и соответствующий файл ffprobe. Поместите их в PATH или рядом с приложением. Приложение не загружает инструменты и не загружает записи.

Откройте «Настройки», чтобы выбрать язык. В разделе «Запись» выберите окно отображения или игры. Windows Graphics Capture поддерживает окна и дисплеи; DXGI поддерживает дисплеи.

## Видео и исполнение

Начните с разрешения 1280 × 720 при 60 кадрах в секунду на встроенной графике, затем измерьте время кадра в игре. По умолчанию остается исходное разрешение. Это рекомендация, а не гарантия производительности.

Автоматическое тестирование реальных аппаратных кодеров. Квантование качественных изменений; скорость меняет усилие энкодера. Точная дробная частота кадров поддерживается до 120 кадров в секунду. Фактическая доставка источника может быть ниже.

При передаче совместимости по умолчанию загружаются кадры в ОЗУ. Это не нулевая копия. Дополнительные работники могут усилить разногласия. Профили никогда не меняют настройки игры и не снижают разрешение или FPS автоматически.

## Аудио

По умолчанию микрофон выключен. Включите его явно в разделе «Аудио» и выберите его устройство. Звук рабочего стола захватывает выбранную конечную точку вывода, а не только одну игру. Используйте наушники.

При необходимости включите смешанное аудио и независимую маршрутизацию треков. Полученный файл содержит настоящие отдельные треки. RNNoise, гейт, экспандер, компрессор, лимитер и усиление можно включить и переупорядочить. Шум клавиатуры может остаться.

Используйте восьмисекундный тест микрофона и воспроизведите сохраненный тест, чтобы оценить четкость. Живой мониторинг наушников и игровой звук, специфичный для процесса, не реализованы.

## Элементы управления записью

F9 запускает или останавливает запись. F10 приостанавливает или возобновляет воспроизведение. F11 отключает микрофон. F7 показывает или скрывает приложение. F8 сохраняет явно запущенный буфер воспроизведения только для видео. Конфликтующие ярлыки можно изменить с помощью горячих клавиш.

Перетащите пользовательскую строку заголовка, чтобы переместить окно. Дважды щелкните его, чтобы развернуть. Закрытие во время записи останавливает и безопасно завершает ее. Исходная иллюстрация не является предварительным просмотром в реальном времени.

## Файлы и восстановление

MKV используется по умолчанию. MP4 и фрагментированный MP4 завершаются после остановки. Звук записывается в коляску PCM и добавляется после остановки. Для завершения длительных сессий может потребоваться время.

Каждый включенный источник стереозвука использует около 1,38 ГБ в час во временном PCM, помимо видео и промежуточных копий. В папках восстановления хранятся оригиналы. Проверьте завершенную запись, прежде чем вручную удалять папку сеанса.

Используйте «Записи», чтобы открывать файлы, конвертировать MKV в MP4 без перекодирования видео или восстанавливать незавершенные сеансы. Исходные записи не удаляются автоматически.

## Ограничения и проверка

В настоящее время при воспроизведении сохраняется только видео. HDR, адаптивная оптимизация, изоляция процесса звука, мониторинг в реальном времени и автоматическое восстановление после сброса графического процессора еще не завершены. Оценивается выравнивание аудио/видео при запуске; проверяйте синхронизацию губ перед важными записями.

Защищенный контент, некоторые эксклюзивные полноэкранные игры и свернутые окна могут перестать отображать кадры. Alt+Tab сохраняет сеанс открытым, но не может снять ограничения операционной системы.

Никакого преимущества в производительности по сравнению с OBS или Xbox Game Bar не установлено. Просмотрите протокол тестирования и статус реализации, чтобы узнать о воспроизводимых тестах и ​​оставшейся работе.
